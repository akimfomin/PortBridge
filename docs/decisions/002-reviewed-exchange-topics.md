# Новые темы в закрытой очереди обмена

Принято 24 ноября 2026 года.

В каталоге мало проверенных карточек, поэтому новый полезный источник раньше нельзя было зарегистрировать. Командам нужен способ согласовать тему, проверить отчёт и передать решение по нему с сохранением авторства.

Одна добровольно подключённая очередь служит источником решений для нескольких клиентов. В ней куратор отдельно проверяет тему и отчёт. Исходный URL обеспечивает дедупликацию и стабильный ID темы. Отзыв отчёта сохраняет решение в истории и добавляет событие для клиентов, которые уже получили отчёт. Клиент MCP может выбрать закрытую очередь через локальный порт и ключ чтения.

Такая схема использует имеющиеся роли и курсор, а для двух установок не требует синхронизировать базы или согласовывать конкурирующие решения. На разных машинах каждая команда подключается к согласованному локальному порту через уже разрешённый защищённый канал.
