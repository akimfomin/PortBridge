# Live public browser

Accepted 25 November 2026.

The public catalog keeps reviewed case cards with their provenance. GitHub sources and related pairs use the complete current export. Each list returns its full result count and serves pages of 48. Exact URL and PR number queries and word and field filters use immutable posting files. Long postings are split into bounded parts. Automatically scored pairs remain candidates. The old matches.json route returns an explicitly marked preview with the full total for existing readers.

The browser follows an immutable index and source snapshots named by the publication manifest. It revalidates the manifest when active, when returning to the tab and on demand. If a new generation is incomplete at an edge, it retains the available previous generation. The page displays publication time and the latest successful source check it can substantiate. The release job verifies all linked snapshots and the browsing generation after GitHub Pages deploys.

The opportunities page uses current radar actions and reviewed links. The previous coordination baseline remains available in the legacy snapshot for historical and API use. The public homepage links measured work, open discussions and separate adoption proof. Test Lab checks indexed receiving revisions and removes already covered equipment from the default runnable queue.

GitHub Actions updates the public data on pushes and the existing schedule. An owner review in a mapped Test Lab issue also runs publication. Its GitHub identity, source repository and issue are pinned. Other comment events cannot run a publication or cancel a pending production run. The scanner still verifies current source comments before export. [Issue comment events](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#issue_comment) · [Scheduled events](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)

Rollback is a revert followed by the existing Pages deployment. Legacy snapshots and canonical asset paths remain available to earlier clients.
