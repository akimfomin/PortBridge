# Independent check of packed quad-mask reconstruction

The direct XCL pixel lowering collects four bits of quad data in a scalar `q` at each physical lane. A wave operation combines these values into emulated mask words. This experiment changes only this final combination. It takes the quad reads, guest EXEC handling, control flow, layout, and mask consumers as given. [XCL baseline](https://github.com/xcl-dev/xcl/blob/e1d84b7d9153f86a97d2ec5d209d196046fc0bea/crates/xcl/src/gpu/dxil/lanes.rs#L466)

## The identity

Consider one execution of the call. Write `A` for its participating physical lanes. Output word `w` is 0 or 1. Bit `4k+p` in that word corresponds to position `p` in the physical quad starting at lane `32w+4k`. XCL ballots bit `p` of every participating lane's `q`. Its two right-shifts and ORs collect the four votes in each quad at its first bit. It keeps that bit and shifts it to position `p`. Therefore the output bit is set exactly when some member of that quad belongs to `A` and has bit `p` set.

Equivalently, lane `l` contributes `(q & 15) << (l & 28)` to word `w` if `l >> 5 == w`, otherwise zero. OR across `A` produces the same bit. The nibbles reported by different participants may disagree. An empty quad contributes zero. Physical lanes 64 and above contribute to neither word. Keep the original output routing for a guest Wave32 running in a larger host wave.

The predicate must select the **value** passed into an unconditionally reached reduction. Splitting execution with a divergent branch around the reduction, selecting only one quad representative, or grouping by a guest lane index changes the participating group. Keep the two reductions adjacent in the same control-flow region as the ballots. Microsoft specifies active non-helper participants by default. Pixel shaders with the SM 6.7 helper-inclusion attribute have a different participant set. [WaveActiveBallot](https://learn.microsoft.com/en-us/windows/win32/direct3dhlsl/waveballot) · [WaveActiveBitOr](https://learn.microsoft.com/en-us/windows/win32/direct3dhlsl/waveallbitor) · [Helper inclusion](https://microsoft.github.io/DirectX-Specs/d3d/HLSL_SM_6_7_Wave_Ops_Include_Helper_Lanes.html) · [Convergent operations](https://llvm.org/docs/ConvergentOperations.html)

## Defined outputs

The identity covers the same dynamic group, the same previously computed inputs, defined low four bits in each contributing input, and observers with defined wave-operation results. DXC documents undefined wave results returned to default-mode helper lanes. A later derivative or quad read that sources one of these values needs a separate argument about the consuming shader. When a quad operation that constructed `q` reads an unavailable invocation, its input definedness must be established separately. The CPU result does not establish hardware equivalence of arbitrary undef or poison propagation. The reference shader already contains these operations. The experiment neither reconstructs helper outputs nor proves that code observing an undefined value will produce matching pictures on a particular driver. [DXC wave semantics](https://github.com/microsoft/DirectXShaderCompiler/wiki/Wave-Intrinsics) · [DXIL](https://github.com/microsoft/DirectXShaderCompiler/blob/main/docs/DXIL.rst)

## Reproduce

Run `python -B packed_quad_oracle.py` with Python 3.10 or later, with assertions enabled. The default seed is 20261126. The exhaustive quad sweep covers all 17⁴ distinguishable combinations of four-bit input and absence. The physical lane basis checks each of the four possible input bits in each lane for host widths 4, 8, 16, 32, 64 and 128. Random calls compare whole-wave outputs under independent execution masks, helper masks and both helper policies. The reducer checks an otherwise identical pair with unknown input in a participating versus absent lane. Four executable, intentionally wrong variants cover two different alias errors on 128 lanes, choosing one representative, and allowing high input bits to spill into another quad.

The default run compared 83,521 exhaustive quad states, 1,008 lane/bit placements, and 12,288 random wave calls. These counts measure modeled coverage. Driver timing, compiled sizes, emitted DXIL, and physical output checks belong to the separate integration experiment. The subgroup ballot and OR primitives are standard operations. The specific XCL lowering and its measured benefit require separate evidence, and this audit does not establish priority for the algebraic identity.
