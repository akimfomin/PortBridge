# Independent review of pixel ballot input simplification

This review concerns the initial producer-only experiment. Later work exercised both complete Mobile NeRF inference draws, the combined lowering and loop-carried mask observations. [Current results](README.md) · [Physical translated and original Mobile NeRF captures](https://github.com/akimfomin/PortBridge/tree/806a4c0dec2364c8881e1efb437964ac4aa42b27/research/pipeline-readiness/structural-suite/night/vulkan/mobile-nerf/translated)

Reviewed XCL `051bdda6..ba83447cd9ce59035cead63bc340135b5e46bc1b` and the supplied structural, corpus, D3D12 and Vulkan records. This review reran the CPU truth-table check and recalculated counts, paired timing differences and stage sizes from the raw records. The hardware receipts are PortBridge's measurements on one RTX 4070 Ti SUPER.

**Correctness.** I found no defined-input counterexample in the changed plain pixel VOPC path. Let `b = lane & ~3` and `p = 0..3`. Then `b|p = b+p`, both positions select the same EXEC word and `(b&31)+p <= 31`. Testing bit `p` of that word shifted by `b&31` equals the old selected-bit test. Guest Wave32 uses the same low EXEC value as before, including when a host mapping has a second half. Guest Wave64 selects high versus low using the same threshold. The original pack uses zero-extended i1 values in disjoint bits, so extracting one bit gives that exact predicate. The same quad-source reads (where required), four member comparisons and four ballots retain their dynamic location and participation. Whole-mask reconstruction and destination writes retain their existing width.

The model returned 393,216 matching ballot operands. Its exhaustive variables are the two four-bit nibbles and guest lane index; four backgrounds exercise adjacent bits. It says nothing about how hardware assigns helper lanes. An undefined or poison source in one comparison can contaminate an entire old packed word. Separating the four i1 inputs can instead yield defined unrelated bits. Claim equivalence for defined contributing values and preserved guest-visible output on tested paths. A guarantee that raw helper values are identical in every execution would require a stronger argument. The changed shader never reads a helper's poison in a new branch condition or newly introduced memory operation.

**Impact beyond the existing SSA consumer.** Of 222 manifest entries, 18 lack prepared inputs, two fail in all three arms, and 202 admit comparison. The producer shrinks 58/202 DXIL modules (54/151 distinct guest byte streams), with zero size increases. Five selected structural records preserve ballot, quad, branch and PHI counts. The baseline includes merged XCL #174, four open XCL changes (#2501, #2503, #2557 and #2446), and the earlier strict same-block SSA consumer. The separate expanded-consumer arm in the cold logs is an alternative. These records cannot establish an additive effect between the two new candidates.

Four D3D12 blocks per arm support the clearest producer-only cold gains on raylib (project → inputs, 799 → 723 ms median, positive in all four blocks) and NeRF71 (1,577 → 1,476 ms, positive in all four). NeRF73 is essentially flat at 1,533 → 1,533 ms. Adding the shared window gives 721, 1,479 and 1,468 ms respectively; its differences against predicates alone change sign across blocks. The opaque cached blob remains identical **in byte length** on all three predicates-only arms. Captured Vulkan fragment Binary Size also stays unchanged for predicates alone; adding the window reduces it by 768, 4,224 and 3,840 bytes on raylib, NeRF71 and NeRF73. This does not establish a D3D12 native-code size or a driver memory ceiling. D3D12 private-byte deltas after creation are distinct from VRAM and from job peak.

All translated Vulkan arms have identical output hashes for each of two raylib cameras. The independently compiled source shader has a different hash. Each translated arm has two fresh workers per camera, each timing five groups of eight draws. Warm GPU intervals overlap. The source shader is substantially faster on this scene (roughly 0.6 versus 4.2–4.5 ms). The producer demonstrates less intermediate arithmetic and modest cold gains, without a demonstrated draw-time or whole-application gain. The two NeRF records are related compile-only shaders.

**Most informative checks before default enablement.** Use a defined position or constant input and explicitly observe both the complete mask and individual bits for aligned quads at lanes 28–31 and 32–35. Provide opposing low/high EXEC masks and cases for all inactive, one active and alternating members; the wrong half must visibly change a color. Include a CMPX updating EXEC followed by a scalar whole-mask reader across divergence and reconvergence, and a widened host subgroup for a guest Wave32 where available. A positive multi-vendor check should exercise triangle edges/helper derivatives plus an independently known scalar mask value. An untouched nonpixel or guarded variant should produce the original module. Normal public translation functions keep their signatures. The public Rust enum constructor changes from a boolean to a mode, so check source users of `Entry::Pixel` if exposing the experimental API upstream. If the wider consumer is combined with this producer, verify four arms on the same baseline and report each marginal contribution.
