# AnyXboxX — lower CPU cost for BC7 texture export

Based on AnyXboxX main `b92a71b9308e76f8ec9059c01d6e18f21611dc20`. The BC7 decoder also appears byte-for-byte in Lewandox’s open [#188](https://github.com/LooperSalty/AnyXboxX/pull/188) at `22c1cf973e7e2ad89fbec8e801d77d287c48729f`. The [patch](anyxboxx-bc7-decode.patch) applies to both revisions. The verified executable used the pinned main source. [Block decoder](https://github.com/LooperSalty/AnyXboxX/blob/b92a71b9308e76f8ec9059c01d6e18f21611dc20/rust/anyxboxx-texture/src/bc7.rs#L221-L273) · [Surface decoder](https://github.com/LooperSalty/AnyXboxX/blob/b92a71b9308e76f8ec9059c01d6e18f21611dc20/rust/anyxboxx-texture/src/lib.rs#L9-L31)

The decoder now keeps up to three BC7 index anchors in a fixed array and tests them through a bit mask. It chooses the color and alpha weight tables once per block. The surface decoder copies visible rows of each decoded block into the image and handles partial blocks at the right and bottom edges. `anchors()` still returns its public ordered vector for callers of the named field API. The new crop test uses a pixel-by-pixel oracle. The existing mode tables, endpoint expansion, interpolation rounding, and reserved block results carry through the optimized path. [Microsoft BC7 format](https://learn.microsoft.com/en-us/windows/win32/direct3d11/bc7-format) · [BC7 modes](https://learn.microsoft.com/en-us/windows/win32/direct3d11/bc7-format-mode-reference)

## Correctness and allocation counts

The standalone fixture links the actual baseline and patched libraries separately. It compared the full RGBA result for 4,560 payloads covering all BC7 modes, partitions, rotations and index selections, 400 image shapes including empty and cropped surfaces, 64 reserved blocks, and malformed lengths. It also compared the public layout fields and anchor ordering. The focused crop test passed on both versions. [Check log](checks.txt)

In the instrumented check, a valid single-block decode made 1 allocation before the patch and 0 after it. A 64×128 image of 512 valid blocks made 513 allocations before and 1 after. The remaining allocation holds the returned RGBA image. A divisible 3840×2160 surface has 518,400 BC7 blocks. The allocation count experiment ran only on the single block and the 512-block image.

## Warm CPU decode times

One four-pair alternating A/B–B/A run on an Intel Core i5‑13600KF, Windows x64, `rustc 1.100.0`, `-C opt-level=3`, default target CPU. Each process prepared deterministic compressed input and performed one untimed decode before measuring. The timed binary installs no allocator instrumentation. Timed calls include the RGBA output allocation. Every sample for a given fixture produced the same output fingerprint. This tests BC7 decoding to RGBA. Tiling, PNG compression, native rendering and game load are outside the timing. [Compiler](compiler.txt) · [All samples](samples.csv) · [Medians](summary.csv)

| Synthetic image | Baseline median | Patched median | Baseline raw range | Patched raw range |
| --- | ---: | ---: | ---: | ---: |
| 3840×2160 | 91.136 ms | 51.856 ms | 90.178–95.696 ms | 51.204–52.520 ms |
| 1919×1079 | 22.184 ms | 12.170 ms | 21.991–22.688 ms | 11.937–12.418 ms |

| 4×4, one block | 206 ns | 136 ns | 195–210 ns | 134–144 ns |

The timing combines anchor, weight selection, and row-copy changes. The instrumentation separately measures the allocation difference. Individual time contributions were not measured.

## Reproduce

From this folder, with Git, Python 3, and a Rust toolchain. The sparse checkout selects the texture crate's source and tests. The runner builds the baseline from the pinned Git object and the candidate from the working copy. The `check` command does not run the benchmark.

```text
git clone --filter=blob:none --no-checkout https://github.com/LooperSalty/AnyXboxX.git anyxboxx-open
git -C anyxboxx-open sparse-checkout set --no-cone "/rust/anyxboxx-texture/src/*.rs" "/rust/anyxboxx-texture/tests/*.rs"
git -C anyxboxx-open checkout --detach b92a71b9308e76f8ec9059c01d6e18f21611dc20
git -C anyxboxx-open apply --check ../anyxboxx-bc7-decode.patch
git -C anyxboxx-open apply ../anyxboxx-bc7-decode.patch
python run_proof.py build --repo anyxboxx-open
python run_proof.py check
python run_proof.py bench --pairs 4
```

The runner accepts `--rustc` and `--linker` overrides and prints the compiler identification. The full AnyXboxX suite and the separate SHA-256 BC7 fixture test were outside the focused check. The inputs are generated by the fixture. The patch retains AnyXboxX’s GPL-3.0-or-later and the upstream MIT attribution to R0Y00/Xbox2Windows in the decoder. [License](LICENSE.AnyXboxX)
