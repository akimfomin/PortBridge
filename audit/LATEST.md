# PortBridge — текущая передача

## Самостоятельный вход и результаты · 28 ноября 2026

- **У каждого запроса по PR теперь отдельное обсуждение.** Форма с главной страницы GitHub принимает публичный PR, вопрос и, при переносе, точный целевой коммит. Поиск и Test Lab также доступны без установки. [Форма](https://github.com/akimfomin/PortBridge/issues/new?template=pr-check.yml) · [Изменение](https://github.com/akimfomin/PortBridge/pull/157)
- **Xbox2Windows получил независимый от автора PR регрессионный прогон.** Сопровождающий подтвердил 12 из 12 сценариев на RTX 4060 Laptop в Debug и Release и выбрал исправление с доказуемой границей ошибки FP16. Для отдельного замера точных значений подготовлена поправка только к тесту. Локально прошли 344 проверки модели. Задание находится в очереди Lab, аппаратный отчёт по четырём значениям ещё открыт. [Результат и решение](https://github.com/R0Y00/Xbox2Windows/pull/3220#issuecomment-7232513116) · [Задание](https://github.com/akimfomin/PortBridge/issues/155)
- **AnyXboxX получил воспроизводимый контроль задержки кэша.** Два разных имени попали в один замок при расчёте по точному коду двух ревизий. У victory-fork есть проверка и кандидат на исправление. Решение AnyXboxX и аппаратный прогон ещё не получены. [Передача](https://github.com/LooperSalty/AnyXboxX/pull/575#issuecomment-7232661796)
- **Приёмка начальной волны сотрудничества NET-05 подтверждена первоисточниками.** В этой итерации нет новых самостоятельных заявок, установок и подтверждённого повторного использования. Исторический результат FrameLab считается отдельно. [Ссылка на шесть обращений и фактические результаты](evidence/adoption-wave-2026-11-28/README.md)
