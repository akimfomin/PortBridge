# PortBridge — текущая передача

## Работа с разработчиками и добровольцами · 28 ноября 2026

- **Получен один независимый аппаратный отчёт.** На RX 9060 XT один и тот же синтетический тест Xbox2Windows дал расхождение на двух версиях. Сопровождающий связал отчёт с проверкой PortBridge. Мы сохранили автора и версии, затем передали безопасную правку теста для раздельной проверки обоих режимов. [Отчёт lambirou](https://github.com/R0Y00/Xbox2Windows/pull/3241#issuecomment-7233177324) · [Решение сопровождающего](https://github.com/R0Y00/Xbox2Windows/pull/3255#issuecomment-7233201943) · [Передача PortBridge](https://github.com/R0Y00/Xbox2Windows/pull/3255#issuecomment-7233284599)
- **Ещё две проверенные заготовки переданы авторам.** Для Xbox2Windows подтвердили 70 из 70 значений FP16 эталоном CPU и обновили запрос для AMD или Intel. FrameLab получил готовую проверку отчёта для запроса на RTX 3060. Реальный повтор обоих тестов пока открыт. [FP16](https://github.com/R0Y00/Xbox2Windows/pull/3220#issuecomment-7233385268) · [FrameLab](https://github.com/5headsmartbtw/leonida-framelab/issues/54#issuecomment-7233384999)

Новых самостоятельных запросов, подключений и повторного использования пока не подтверждено. [Открытое приглашение](https://github.com/akimfomin/PortBridge/issues/112)
