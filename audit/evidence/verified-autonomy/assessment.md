# PortBridge · передача результатов и плановые публикации · 27 ноября 2026, МСК

## Из Radar в Test Lab

В [PR #129](https://github.com/akimfomin/PortBridge/pull/129) ревьюер может превратить найденную строку лицензированного исходника в готовую проверку Lab. PortBridge сверяет текущий открытый PR, обе ревизии, строку и лицензию до подготовки, выдачи и обработки задания. Для черновика нужны наблюдаемый результат, отрицательный контроль и явное согласие публиковать текст проверки. У кандидата сохраняется статус найденного источника. Отдельное подтверждение нужно для результата и решения принимающей команды.

Проверили ход `prepare → queue → claim` на контролируемом примере из исходников. Повтор с переставленными JSON-полями вернул тот же черновик. Без прав ревьюера и согласия на публикацию запрос отклоняется. Локальный путь в тексте не сохраняется. Смена исходного PR или удаление сравнительного файла из индекса блокирует дальнейшее выполнение до очередного обновления Radar. Отчёта внешнего добровольца по этому новому пути пока нет. [Код кандидата](https://github.com/akimfomin/PortBridge/commit/49c16c7e15e439a3b1b2034f281a4121ae2f1dd0) · [Инструкция](https://github.com/akimfomin/PortBridge/blob/49c16c7e15e439a3b1b2034f281a4121ae2f1dd0/docs/TEST-REQUESTS.md#turn-a-discovered-source-into-a-lab-check)

В работающем Radar нашли ложные исходные карточки, где названия запусков CI вроде `PR checks` использовались как запросы для поиска реализации. На исходной выгрузке таких карточек было 27, из них 10 активных. Ограничили вход задачами, PR и коммитами, а существующие карточки этой категории переводятся в устаревшие. Radar также пересчитывает выдачу при изменениях проиндексированных строк. [Выдача до правки](radar-baseline.json)

Облачная проверка вскрыла перенос Continued. Старый API вернул 301 для GitHub repository ID `1469441675`. Публичный [ProjectLeonida/mandy](https://github.com/ProjectLeonida/mandy) имеет тот же ID, закреплённый коммит данных и проверенную лицензию. Обновили адрес загрузки, сохранили общий идентификатор для старых и новых ссылок. После исправления полная локальная сборка нашла 71 из 71 файла, включая пять файлов Continued. ## Внешние проверки

Сверили две опубликованные проверки статических сэмплеров. KyleS98 сообщил о смене результата PipelineLibrary на RTX 3090 Ti, UncommonDLL получил ожидаемый результат самостоятельного теста на RTX 5070 Ti. В XCL предложили зафиксировать одну конфигурацию и сопоставить оба пути кэша с результатом без кэша при изменении порядка создания сэмплеров. На этом этапе у PortBridge есть отправленное сравнение и критерий решения. Ответа автора и нового замера пока нет. [Обсуждение XCL](https://github.com/xcl-dev/xcl/issues/3044#issuecomment-7227504938)

У Xbox2Windows остаётся открыта правка фильтра адаптера. Когда RonLogic опубликует точную ревизию, полезны два контроля на Arc B580. Корректный фильтр выбирает Intel, заведомо неверный завершает запуск до отправки GPU-команд. Результат vivensid по KytyPS5 пока ожидается. По XCL Scratch на прежнем черновике новых парных замеров нет. [Xbox2Windows](https://github.com/R0Y00/Xbox2Windows/issues/3052#issuecomment-7226021506) · [KytyPS5](https://github.com/akimfomin/PortBridge/issues/100) · [XCL](https://github.com/xcl-dev/xcl/pull/2322)
