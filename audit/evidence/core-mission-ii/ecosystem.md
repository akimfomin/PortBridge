## A current cross-backend handoff

**Xbox2Windows direct DXIL and AnyPS5 SPIR-V implement the same ISA conversion.** On RTX 5090 driver 32.0.16.1088, pigalot independently measured a compiled literal `0.5 → 1` in packed U8 conversion and a lane-derived `0.5 → 0` on the same adapter. The other 15 cases in the fixed input table passed. The literal still used DXIL `Round_ne` before driver compilation. This leaves a plausible but unproven driver constant-folding issue. The two separate SDWA failures in the same report are due to a comparator looking for high bits in an extracted half. The proposed SDWA fix explicitly excludes the rounding discrepancy. [Xbox2Windows #3052, opened at 11:51:16Z](https://github.com/R0Y00/Xbox2Windows/issues/3052), [#3053, opened at 11:55:15Z](https://github.com/R0Y00/Xbox2Windows/pull/3053), [first tested SHA](https://github.com/R0Y00/Xbox2Windows/commit/1c879506bc6f7eee8a3b399d32d82025151b1daf), [second tested SHA](https://github.com/R0Y00/Xbox2Windows/commit/98007de5de362c32c6d926f3430c4ba9d496e943).

AnyPS5 independently addressed the same conversion by spelling out ties to even rather than depending on a SPIR-V rounding intrinsic. It characterized the expected result on gfx1035 and exercised literal ties in its change. This is a mechanism, reference and alternative, without a demonstrated DXIL correction. MIT Xbox2Windows and GPL-2.0 AnyPS5 call for fresh implementation following the arithmetic contract rather than copying implementation. The portable comparison can first add a very cheap lane-derived and literal pair at `0.5, 1.5, 2.5, 254.5` and one binary32 step on each side. A test author can then try an independent lowering using integer truncation and `fraction > 0.5 || (fraction == 0.5 && odd)` if both controls show a mismatch limited to the direct path. Preserve input range treatment and surrounding packed bytes. DXIL optimization may recognize the expression and reintroduce `Round_ne`, so inspect the emitted operations and compare literal versus runtime in the actual GPU test. Need physical AMD and a true WARP run. [AnyPS5 #501, merged 2026-10-05 13:32:07Z](https://github.com/boykopovar/AnyPS5/pull/501), [exact AnyPS5 code](https://github.com/boykopovar/AnyPS5/blob/4c57426b51b5f8a9419bb2aa518ca2244f74866f/core/shader/recompiler/Translation/src/ConvertInstructions.cpp#L173-L185), [DXIL unary operations](https://github.com/microsoft/DirectXShaderCompiler/blob/main/docs/DXIL.rst).

Local CPU control compared the mathematical formula after mapping negative/NaN to zero and saturating at 255 with Python Decimal's exact ties-to-even conversion. All 10,776 input checks matched, including all 255 representable nonnegative half ties through 254.5 and their two immediate binary32 neighbors, 11 special values, and 10,000 binary patterns drawn with seed 10292. This proves agreement only on the exercised CPU inputs. No GPU timing, DXIL lowering, packed-destination behavior or NVIDIA fix was measured by PortBridge.

Save this standalone check as `rounding-control.py` and run `python -I rounding-control.py`.

```python
import random
import struct
from decimal import Decimal, ROUND_HALF_EVEN


def bits(value):
    return struct.unpack('<I', struct.pack('<f', value))[0]


def explicit(value):
    value = 0.0 if not value > 0 else min(255.0, value)
    integer = int(value)
    fraction = value - integer
    return integer + int(fraction > 0.5 or (fraction == 0.5 and bool(integer & 1)))


def oracle(value):
    if not value > 0:
        return 0
    if value >= 255.0:
        return 255
    return int(Decimal.from_float(value).to_integral_value(rounding=ROUND_HALF_EVEN))


rng = random.Random(10292)
ties = [bits(n + 0.5) + offset for n in range(255) for offset in (-1, 0, 1)]
special = [0, 0x80000000, 1, 0x80000001, 0x7f800000, 0xff800000,
           0x7fc00000, 0xffc00000, bits(255.0) - 1, bits(255.0), bits(255.0) + 1]
cases = ties + special + [rng.getrandbits(32) for _ in range(10000)]
for word in cases:
    value = struct.unpack('<f', struct.pack('<I', word))[0]
    assert explicit(value) == oracle(value), (hex(word), value)
print(f'{len(cases)} CPU checks passed')
```
