# PortBridge technical operations, three waves

## Work completed

The three batches cover resource lifetime and memory transfers, rendering and shader behavior, then timing and cache measurements. 188 public open PRs were pinned after excluding the previous wave's records. 185 could be mechanically checked against the receiving branch (149 clean, 35 conflicts, one already present). Three DirectXShaderCompiler trials did not complete. 126 pairs with overlapping source files and the same receiving branch were mechanically checked (77 clean, 46 conflicts, three already present). These are Git results for captured revisions. Runtime compatibility needs a separate run.

There are 51 cross-project source comparisons with concrete receiving-side controls below. A source relationship or a common test input does not require the implementations to converge. The local CPU run executed 55 controlled scenarios: 14 delayed-readback traces, 10 interleavings of a dirty writer and reader, 16 present-count cases, two explicit negative controls, 12 register-index model groups and one independently compiled upstream Rust test. Seven test functions contain those scenarios. No physical GPU or title was used locally.

40 distinct PR authors have confirmed public deliveries. 30 have no earlier delivery in the previous tracked wave records or the conservative known-contact set used here. 23 new tester matches were found against existing requests; 12 individual invitations were delivered. No uncontacted roster is attached. Public replies and benchmark ownership remain with the respective authors. There are no confirmed third-party agent installations or newly observed autonomous agent usage. Agent use issues and Lab requests stay opt-in.

## Decisions and follow-through

- **Vice-Tay accepted the test in its PR.** A bounded PortBridge enumeration found that taking the dirty work before clearing its queue flag can leave a later notification unprocessed. [urielbeaupre added the corresponding runtime test](https://github.com/TaynanGT/Vice-Tay/pull/392#issuecomment-7232139054) at [`b45345c1`](https://github.com/TaynanGT/Vice-Tay/commit/b45345c1ed7011b1b8441511a7228ee44989d49d), with a deterministic writer between the flag clear and the range read. The two drains see each range exactly once and a third is empty. The author reported a 529-test passing run and one intermittent write-watch failure on another run. Whether it reproduces on unchanged main remains open. [PortBridge confirmed a clean mechanical merge and returned the evidence](https://github.com/TaynanGT/Vice-Tay/pull/392#issuecomment-7232162172). The PR remained open. One newly confirmed cooperation.
- **Continued independently checked the prior soft-cap test.** [timbot103](https://github.com/ProjectLeonida/mandy/pull/2517#issuecomment-7231757105) ran the updated source and confirmed the 63 → 67-byte case. This is additional evidence for an existing transfer. The open PR was not merged at the last check.

## Reproduce

- Review [pinned inputs](pull-requests.json), [Git results](git-results.json) and the [patch comparison script](merge_trials.py). On Windows run `$env:PB_OPS_REPORT_FILE = 'git-results.json'; python -X utf8 -I merge_trials.py` from a throwaway directory. It fetches public Git refs into temporary bare repositories and excludes heads that moved during fetch. A clean merge is only a text/tree check. 
- Run `python -I test_cpu_controls.py` and `python -I test_indexed_reads.py`. These are bounded CPU models.
- Fetch only the reviewed [KLBF source file](https://raw.githubusercontent.com/PastiiJay/klbf-lab/d18474523030d0bda09080b48dd52c3a197bead4/crates/victory-gpu/src/ffx.rs) to `ffx.rs`. Run `python -I extract_present.py ffx.rs present_control.rs`, `rustc --test present_control.rs -o present_control.exe`, then run the executable locally to repeat the pinned upstream check. The output and hash are in [test receipts](test-receipts.txt).
- Run `python -I replay_readback.py <checkout>` with the baseline checkout and then with the merged revision. The adjacent [search titles](search-titles.json) are the same inputs for both. The anonymous [live receipt](discovery-results.json) includes the CLI output for `python -m portbridge.preflight --url https://github.com/LooperSalty/AnyXboxX/pull/574 --limit 5`.
