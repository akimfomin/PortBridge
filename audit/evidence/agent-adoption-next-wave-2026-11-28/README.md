# PortBridge · следующая волна вовлечения

## Публичный путь к заявке

Главная страница направляла ссылки на PR в общий индекс источников. У этого режима не было перехода к форме. #160 направляет точный публичный PR в каталог с результатами Discovery и ссылкой на существующую форму. Обычные запросы всё ещё используют индекс источников. Форма также доступна на двух языках со страницы начала работы. Отправка остаётся явным действием пользователя в GitHub. [Изменение #160](https://github.com/akimfomin/PortBridge/pull/160) · [Запуск Pages](https://github.com/akimfomin/PortBridge/actions/runs/46101993131)

На точном коде прошли 336 тестов, проверка синтаксиса JavaScript и проверка локального экспорта. Три сценария в браузере охватывают ввод PR с главной, отсутствие результата и найденные строки исходника. Для Markdown-ссылок на собственную задачу можно отправить разработчику [саму форму](https://github.com/akimfomin/PortBridge/issues/new?template=pr-check.yml). Для агента без установки подходит [стартовая страница](https://akimfomin.github.io/PortBridge/start.html). Форму также добавили в существующее [открытое приглашение #112](https://github.com/akimfomin/PortBridge/issues/112) без нового комментария или упоминания участников.

## AMD-прогон Xbox2Windows #3255

`346da2ba5409079ad1083f84ad883b0fc2aee13b` использует линейный индекс, восстановленный из номера волны и номера потока. CPU-контрпример переставляет две целые четвёрки внутри одной волны. При размере группы 12, 32, 96 или 128 сохраняются позиции внутри каждой четвёрки. Восемь полных индексов при этом меняются. Это демонстрация предела гарантии спецификации. Такая перестановка на AMD пока не наблюдалась. [Спецификация SM 6.6](https://microsoft.github.io/DirectX-Specs/d3d/HLSL_SM_6_6_Derivatives.html#1d-quads) · [Документация автора](https://github.com/R0Y00/Xbox2Windows/blob/346da2ba5409079ad1083f84ad883b0fc2aee13b/docs/experiments/native-compute-implicit-derivatives.md)

Автор сообщил об RTX 5080 на закреплённой версии, R0Y00 проверил более раннюю версию на RTX 4060 Laptop. Для AMD подготовлен повтор исходного синтетического теста и структурированный приём результатов. Тестер получил одно добровольное предложение, выбранное по [опубликованному прогону на AMD RX 9060 XT](https://github.com/xcl-dev/xcl/pull/2670#issuecomment-7189509075). Результат пока открыт. Во время публикации PR принят в `0fe4cebcbc78f6b020a95f6df8f1ff0e9c3ffc86`. Семь из восьми изменённых файлов побайтно совпадают с проверявшейся вершиной. В восьмом файле интегрированы дополнительные проверки изображения и скалярных операций. Задание #159 переведено на точный коммит слияния. [PR #161](https://github.com/akimfomin/PortBridge/pull/161) вошёл в main под `4b3378af870d8b3fac78bb50ffd019c886a056ba`. Публикация и её проверка прошли. Живой JSON и MCP независимо от локальной базы вернули новый SHA и состояние `needs_run`. Локальная проверка приёма синтетического отчёта распознала новый SHA и исключила прежний. [Рабочая карточка Lab](https://akimfomin.github.io/PortBridge/#/lab?task=xbox2windows-3255-implicit-derivatives) · [Публикация](https://github.com/akimfomin/PortBridge/actions/runs/46102907692) [Принятый коммит](https://github.com/R0Y00/Xbox2Windows/commit/0fe4cebcbc78f6b020a95f6df8f1ff0e9c3ffc86) · [Отчёт автора](https://github.com/R0Y00/Xbox2Windows/pull/3255#issuecomment-7232743466) · [Задание](https://github.com/akimfomin/PortBridge/issues/159) · [Приглашение](https://github.com/akimfomin/PortBridge/issues/159#issuecomment-7232864908)

## Переносы и проверки

- **AnyXboxX #571.** Автор принял предложенный межпроектный контроль и на head `446fb7a691a2ded94f23abf549dfc8bf1f5b3e20` проверил размеры 9, 19 и 129, первый исключённый индекс, соседние степени двойки и старшие биты. Старый и новый код прошли проверку на RTX 4060 Laptop, Intel UHD и WARP. Это прежний авторский результат, впервые включённый в эту передачу. Он не является новым независимым прогоном или слиянием. У VIctory есть отдельный программный контроль 7/8/9. Возврат результата в #3630 через интеграцию GitHub получил 403 и не был опубликован. [AnyXboxX](https://github.com/LooperSalty/AnyXboxX/pull/571#issuecomment-7231333067) · [VIctory](https://github.com/Marvisak/VIctory/pull/3630#issuecomment-7231030168)
- **XCL #3086.** andrewDoing обнаружил на коде XCL 961 попытку вместо 16 при отказах финальной записи. На `f147360f0e919c2ab5c262ab20564d8e90739a05` подготовлена [поправка](bound-receipt-checkpoints.patch), которая отделяет счётчик новых записей после последней попытки от числа несохранённых записей. Повторная явная запись работает в обход порога. Модель подтвердила 16 попыток для исправного и недоступного хранилища, а также запись всех 1 024 записей после восстановления. Поправка прошла `git apply --check` и фактическое применение к закреплённому исходнику. Сопровождающие XCL приняли тот же принцип и независимо реализовали и проверили его на `fdbac840ba68b1706136564fbcfa8ddffb1d5b8d`. Прежняя поправка PortBridge сохранена для сравнения. Пробу раннего явного сохранения после 65 записей проверили на модели. Интеграция GitHub вернула 403 для комментария об этой пробе, поэтому в обсуждении её нет. [Исправление автора](https://github.com/xcl-dev/xcl/pull/3086#issuecomment-7232935141) · [Независимая проверка исходной версии на Windows](https://github.com/xcl-dev/xcl/pull/3086#issuecomment-7232918376) [Проба автора отчёта](https://github.com/xcl-dev/xcl/pull/3086#issuecomment-7232854888) · [Команда модели](verify_retry_cadence.py)
