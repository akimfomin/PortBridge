# KLBF Lab · BM-v1 pilot

## Decision under test

Can a contributor use a released PortBridge Test Lab request to find a KLBF control for an existing RX 9070 XT result and decide whether the pair can support an A/B comparison? KLBF's board already publishes individual results. Its AMD reference and the contributor's corrected result share the nominal profile, upscaling label and texture cap. They come from different machines. The reference JSON also leaves the FSR version and driver unspecified. Comparing these two rows establishes an observation and leaves the cause of the lower-tail difference open. The current measurement RFC is still open and calls for repeatable runs. ## Released Test Lab and participant outcome

- Opened a custom request using the released Test Lab's [request form](https://github.com/akimfomin/PortBridge/issues/new?template=test-request.yml). The published issue carries the full build commit, GPU and comparison fields. The v0.2.0 parser accepted the exact issue body and resolved the GPU as `amd / rx 9070 xt`. The request is discoverable through [Test Lab → View test requests](https://github.com/akimfomin/PortBridge/issues?q=is%3Aissue+%22Test+request%3A%22+in%3Atitle). The live GitHub queue included #95. It remains a GitHub request with no automatic partner-feed entry. [Live request](https://github.com/akimfomin/PortBridge/issues/95) · [Released form](https://github.com/akimfomin/PortBridge/blob/49bf084250ec55c70d6732000ea40e62c3d36b4c/.github/ISSUE_TEMPLATE/test-request.yml)
- Sent BrokeAsh one voluntary invitation in that issue. They can use the checklist with existing public reports and return a qualifying permalink or state what prevents the comparison. No repository installation or new benchmark is required to answer. PastiiJay's completed XCL #1100 check and later declined Wave64 invitation are separate historical contacts. [Sent invitation](https://github.com/akimfomin/PortBridge/issues/95#issuecomment-7203842475) · [Prior completed request](https://github.com/akimfomin/PortBridge/issues/14#issuecomment-7144197746) · [Prior decline](https://github.com/akimfomin/PortBridge/issues/63#issuecomment-7166677895)
- At the latest check the only comment was the invitation. There is no demonstrated use or decision on this new task. The BM-v1 results and KLBF approvals in the table preceded the pilot. [Current discussion](https://github.com/akimfomin/PortBridge/issues/95)

The maintainers supplied the comparison criteria and selected the invitation recipient by reading the original threads. Submitting a matched report, deciding whether the comparison is fair and recording an independent decision are manual. PortBridge supplies the persistent request and scope.
