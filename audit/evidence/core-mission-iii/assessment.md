## Корпус и эксплуатация

После четырёх запросов Git trees получено 40 файлов восьми проектов вместо 16 файлов семи проектов. Отбираются текстовые Git blobs из утверждённых каталогов с ограничениями на путь, тип и размер. Индекс хранит технические признаки, номера строк и SHA-256, а Git blob сверяется при загрузке. Один повтор занял 0,395 с с 40 кэшированными файлами и нулём чтений дерева. Переход между пинами с неизменным blob проверен тестом. Обновление пинов и лицензионное решение сохраняют ручное ревью. История функций и патчей в этот индекс не вошла.

Локально прошли 313 тестов, включая работу Chrome с одним точным совпадением без карточки задачи. Пройдена проверка экспорта. Страница использует до двух строк для 96 недавно обновлённых публичных задач из снимка. Локальный API, preflight, CLI, MCP, Radar и Action опираются на общий слой кандидатов. Сценарий рабочего GitHub Action в стороннем репозитории на этой версии не повторялся. Облачный ручной запуск прошёл тесты, экспорт и проверку публикации, шаг загрузки исходников и развёртывание пропущены условиями workflow. В main продолжает работать прежний поисковый код.
