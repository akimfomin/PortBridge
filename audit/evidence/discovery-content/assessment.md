## Отдельное исправление нормативных ссылок Vulkan

[Ревизия `0ca21bb`](https://github.com/akimfomin/PortBridge/commit/0ca21bb60d20c35fcfe3344348b8c2ee1cb449b0) распознаёт действующий блок `refpage` в AsciiDoc и поднимает его только при совпадении API с технической темой заголовка. Исключены листинги, комментарии, passthrough и сломанные объявления. На ранее просмотренной выборке нормативный поиск вырос с 0/6 до 1/6. Для [Vulkan-ValidationLayers #11750](https://github.com/KhronosGroup/Vulkan-ValidationLayers/issues/11750) найдено правило, по которому сопоставления входных вложений должны совпадать с привязанным конвейером. Это контроль после изучения причины промаха. [Правило Vulkan](https://github.com/KhronosGroup/Vulkan-Docs/blob/81b1d516cbf42f04a3c7f781977c499945b5e5dc/chapters/interfaces.adoc#L774-L797) · [Повтор прежней выборки](refpage-exploratory.json)

## Воспроизведение

На ревизии эксперимента и с отдельными базами:

```sh
python -B -m portbridge.code_search --db .portbridge/base.sqlite3 --refresh --require-complete
python -B -m portbridge.code_research --db .portbridge/research.sqlite3 --refresh
python -B -m unittest discover -s tests -v
```

Из ветки аудита:

```sh
python -B audit/evidence/core-mission-iii/replay.py PRODUCT_CHECKOUT BASE_DB audit/evidence/discovery-content/holdout.json --research-db RESEARCH_DB
```

Для прежней выборки передайте `audit/evidence/discovery-mechanism/holdout.json`. Повтор берёт публичные описания по URL и требует совпадения хеша. При лимите GitHub можно воспользоваться сохранёнными публичными API-ответами в локальном JSON-массиве с полями `url`, `title`, `body` через `--inputs`. В отчёт вошли URL, хеши, параметры и итоговая выдача. Исходные метаданные участников и SQLite не публиковались.
