Разработчик может сверить результаты этих четырёх значений на своей реализации. Ранее поиск пропускал исполняемый шейдер в строке C++ и мог принять пример из комментария за тест. На трёх ранее подтверждённых межпроектных случаях это даёт 0/3 → 1/3. Ещё одно попадание на широкой выборке — конкретное правило Vulkan для зависимостей в render pass. ## Воспроизведение

В каждой из двух рабочих копий PortBridge, на ревизиях выше, выполните команды. Для точного сравнения проверьте, что исходники кандидата совпадают со списком ревизий и SHA-256 из опубликованного манифеста. В измеренном прогоне отбор использовал метаданные деревьев закреплённых ревизий, а содержимое файлов сверялось с хешами Git. Новое обновление через GitHub может получить более свежие ревизии.

```sh
python -B -m portbridge.code_search --db .portbridge/mechanism.sqlite3 --refresh --require-complete
python -B -m portbridge --db .portbridge/mechanism.sqlite3 export --out .portbridge/assessment-site --repository akimfomin/PortBridge
python -B -m portbridge.release_gate .portbridge/assessment-site
python -B -m unittest discover -s tests -v
```

Из ветки аудита запустите повтор для каждой подготовленной базы. Повтор загружает публичное описание задачи и останавливается, если его хеш изменился.

```sh
python -B audit/evidence/core-mission-iii/replay.py PRODUCT_CHECKOUT INDEX_DATABASE audit/evidence/discovery-mechanism/holdout.json
```
