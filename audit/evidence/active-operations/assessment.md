# Активная эксплуатация PortBridge · 28 ноября 2026, МСК

## Переданные результаты

- **Vice-Tay → VIctory.** В слитом Vice-Tay #258 есть проверки разделения дескрипторов и ограничителей индекса в сгенерированном DXIL. В открытом VIctory #2122 аппаратный тест покрывает raw-буфер. Предложили использовать готовую проверку DXIL для структурированного буфера, с ограничением кучи и без него, прежде чем переносить более широкие изменения оптимизатора. KingKaom подтвердил чистое создание 25 715 конвейеров на RX 9070 XT, драйвер 32.0.32029.2010, в Vice-Tay e0cdb09. JAEdotUK независимо подтвердил 4/4 сбоев старого варианта и 5/5 успешных прогонов варианта #2122 на другом драйвере, 32.0.32015.7029. Аппаратные данные принадлежат авторам. Предложенная проверка структурированного буфера на VIctory пока не выполнена. [Исходник Vice-Tay](https://github.com/TaynanGT/Vice-Tay/blob/927da4079031d74cc987de30a3c00af28a2bf631/crates/victory-shader/src/emit/size_tests.rs#L556) · [Прогон Vice-Tay](https://github.com/TaynanGT/Vice-Tay/issues/163#issuecomment-7227831555) · [Прогон VIctory](https://github.com/Marvisak/VIctory/pull/2122#issuecomment-7228373145) · [Передача PortBridge](https://github.com/Marvisak/VIctory/pull/2122#issuecomment-7228701565)
- **Vice-Tay → AnyXboxX.** Issue #534 уже назвало источник. PortBridge проверил статическую совместимость трёх файлов Vice-Tay #293 с AnyXboxX `bebcfb104aebbcb081a2b2f2233d5c3c009a4250`. Из API GitHub взяли патчи трёх файлов `crates/victory-hle/`, проверили наличие файлов на обеих ревизиях, добавили префикс `third_party/victory` и выполнили `git -c core.autocrlf=false apply --check --index` и `git -c core.autocrlf=false apply --index` в отдельном временном репозитории с исходными файлами AnyXboxX. Два изменённых файла совпали с исходными результатами Vice-Tay, в третьем сохранились свои объявления AnyXboxX. Документ чужого форка исключён. Запуск тестов на принимающей версии и вопрос включения по умолчанию открыты. Код в чужой репозиторий не отправлялся. [Патч Vice-Tay](https://github.com/TaynanGT/Vice-Tay/pull/293/files) · [Итог обеих ревизий](anyxboxx-dsp-apply.json) · [Передача PortBridge](https://github.com/LooperSalty/AnyXboxX/issues/534#issuecomment-7228738668)
