# Проверка поиска по техническим признакам

27 ноября 2026 года, МСК. Рабочая база `bcf645519a7cb1a302f5e426b883786bd7a24a05`. Эксперимент сохраняет ограниченный набор технических признаков из описания задачи и использует их при выборе строки в коде. Проверены обработка локального и публичного поиска, 310 тестов и экспорт. [Код опыта](https://github.com/akimfomin/PortBridge/commit/877da35de766df50fccf892658f7e6d8f57f5a92)

## Результаты

| Набор | База | Эксперимент |
| --- | ---: | ---: |
| Три PR, использованные при разработке правил | 0/3 даже с добавленными файлами | 3/3 на первом месте |
| Три независимые задачи с заранее указанными строками, первые пять результатов | 0/3 | 0/3 |

В известных PR нужными строками стали проверка безопасности переноса инструкций в LLVM (1467), проверка попадания в кэш в Continued (160) и запуск цепочки очередей в Vulkan CTS (1692). [Исходный контроль с добавлением файлов](../core-mission-ii/coverage-probe.json)

Независимая контрольная выборка содержит пять публичных задач. Её зафиксировали до первого прогона и подбирали среди тем с уже имеющимися исходниками. Она оценивает совпадение с заранее заданной строкой и не измеряет охват внешних репозиториев. [Разметка](holdout.json) · [Выдача базы](baseline.json) · [Выдача опыта](candidate.json)

- XCL #810. Обе версии нашли правильный файл Wine, но сослались на соседнюю функцию. Точное имя API присутствовало во входе.
- vkd3d-proton #945. Ссылка базы вела на восемь строк выше нужного определения. Добавленный тест CTS занял первое место, хотя не пояснял искомое правило.
- SDL #14518. В базе правильный файл оказался пятым с другой строкой. Тест CTS вытеснил файл из пятёрки.
- На двух отрицательных задачах общий словарный поиск выдавал совпадения. Такие ссылки остаются кандидатами для проверки, их наличие не подтверждает перенос.

Эксперимент оставлен на проверочной ветке. Общий критерий SEARCH-08 остаётся открытым. Для повторного прогона скрипт принимает checkout, индекс SQLite соответствующей версии и локальный JSON с пятью текстами. Скрипт сверяет исходные хэши и сохраняет только результаты поиска. [Скрипт](run.py)
